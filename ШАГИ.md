# Что делать — по шагам

Всё выполняется в **PowerShell** из этой папки. Открой её в VS Code → Terminal → New Terminal.

```powershell
cd "$HOME\projects\lakehouse"
```

Конфигурация подобрана под твою машину: **scale factor = sf1** (6 млн строк, ~0.7 ГБ сырых).
На диске всё вместе займёт ~8 ГБ с docker-образами. 16 ГБ RAM хватает с запасом.

## Шаг 1 — поднять стенд (~5-10 мин, качает ~2 ГБ образов)

```powershell
.\00_setup.ps1
```

Скрипт сам делает всё, что в гайдах 1-2 расписано руками: MinIO, 3 бакета,
Postgres, миграции и запуск Lakekeeper, bootstrap, 3 warehouse, Trino с каталогами.

В конце должно напечатать `=== Стенд поднят ===` и список каталогов:
`bronze, gold, silver, system, tpch`.

**Проверь глазами** (нужно для скриншотов в отчёт):
- MinIO http://localhost:9001 → `minioadmin` / `minioadmin` → Buckets: bronze, silver, gold
- Lakekeeper http://localhost:8181/ui/ → Warehouses: 3 штуки в статусе active

> Если что-то упало — пришли мне вывод `docker ps -a` и `docker logs trino`.

## Шаг 3 — Бенчмарк: 8 таблиц = 2 формата × 4 кодека (~20-30 мин)

```powershell
python 02_benchmark.py --sf 1
```

Это и есть «загрузить сырые данные в двух форматах с тремя кодеками» из задания
(кодеков делаем 4, а не 3 — запас по баллам) **плюс** все замеры сразу:

| Что мерится | Как |
|---|---|
| время записи | wall clock вокруг `CREATE TABLE AS SELECT` |
| размер данных | `sum(file_size_in_bytes)` из `"<table>$files"` |
| число файлов | `count(*)` оттуда же |
| метаданные | `sum(length)` из `"<table>$manifests"` |
| агрегация cold | TPC-H Q1 после `docker restart trino lakehouse-minio` |
| агрегация warm | тот же запрос сразу повторно |

Скрипт перезапускает стек перед каждым cold-замером — 8 раз по ~20с. Без этого
второй и последующие замеры врут из-за прогретого кэша.

На выходе: **`results.csv`** и `results.json` в этой папке. Их пришли мне.

> Долго / мало места? `python 02_benchmark.py --sf 1 --no-restart` — вдвое быстрее,
> но cold-замеры станут недостоверными, я отмечу это в отчёте как ограничение.

## Шаг 4 — Silver и Gold (~2-3 мин)

```powershell
.\01_run_sql.ps1 sql\03_silver.sql
.\01_run_sql.ps1 sql\04_gold.sql
```

- **Silver**: отчёт о качестве данных, SCD Type 2 по клиентам, очищенный и
  обогащённый факт продаж (decimal вместо double, коды → читаемые значения,
  расчёт net/скидки/просрочки, join с заказами и товарами).
- **Gold**: три витрины — выручка по регион×сегмент×месяц, качество логистики
  по способу доставки, возвраты по бренду.

**Скопируй вывод обоих скриптов целиком** (контрольные SELECT в конце печатают
цифры, которые нужны в отчёт) и пришли мне.

## Если упало

| Симптом | Причина / лечение |
|---|---|
| `port is already allocated` | `Get-NetTCPConnection -State Listen -LocalPort 8080` → убей процесс или смени порт в `00_setup.ps1` |
| `Catalog 'tpch' not found` | Trino не перезапущен после правки `catalog\` → `docker restart trino` |
| Trino падает на старте | `docker logs trino`; обычно опечатка в `.properties` |
| `pool timed out` у Lakekeeper | Postgres не успел → `docker restart lakekeeper` |
| `pull access denied` на MinIO | нужен форк `pgsty/silo`, он уже в скрипте |
| Query exceeded memory | уменьши sf или добавь Docker Desktop RAM (Settings → Resources) |
| Docker не видит `catalog\` | путь с кириллицей/пробелами — перенеси папку |
