# Как воспроизвести

Всё выполняется в PowerShell из папки проекта. Можно открыть её в VS Code -> Terminal -> New Terminal.

```powershell
cd "$HOME\projects\lakehouse"
```

Настройки под ноутбук с 16 ГБ RAM: scale factor `sf1` (6 млн строк, ~0.7 ГБ сырых данных). На диске всё вместе с docker-образами занимает ~8 ГБ.

Если не хочется идти по шагам, `run.cmd` делает всё подряд.

---

## Шаг 0. Подготовка (один раз)

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
pip install trino
docker --version      # если не отвечает, запустить Docker Desktop
```

---

## Шаг 1. Поднять стенд (~5-10 мин, скачивается ~2 ГБ образов)

```powershell
.\00_setup.ps1
```

Скрипт делает то же, что в гайдах 1-2 делается руками: MinIO и 3 бакета, Postgres, миграции и запуск Lakekeeper, bootstrap, регистрация 3 warehouse, Trino с каталогами.

В конце печатается `=== Стенд поднят ===` и список каталогов: `bronze, gold, silver, system, tpch`.

Проверка:
- MinIO http://localhost:9001 (`minioadmin` / `minioadmin`) -> Buckets: bronze, silver, gold
- Lakekeeper http://localhost:8181/ui/ -> Warehouses: 3 штуки в статусе active

Если что-то не поднялось, смотреть `docker ps -a` и `docker logs trino`.

## Шаг 2. Bronze (~1 мин)

```powershell
.\01_run_sql.ps1 sql\01_bronze.sql
```

Загружаются orders, part, nation, region и две партии клиентов. Во второй партии у части клиентов меняется сегмент.

## Шаг 3. Бенчмарк: 8 таблиц = 2 формата x 4 кодека (~20-30 мин)

```powershell
python 02_benchmark.py --sf 1
```

Это загрузка сырого `lineitem` в Bronze в разных форматах и кодеках, и сразу все замеры:

| Что мерится | Как |
|---|---|
| время записи | время выполнения `CREATE TABLE AS SELECT` |
| размер данных | `sum(file_size_in_bytes)` из `"<table>$files"` |
| число файлов | `count(*)` оттуда же |
| метаданные | `sum(length)` из `"<table>$manifests"` |
| агрегация cold | запрос после `docker restart trino lakehouse-minio` |
| агрегация warm | тот же запрос сразу повторно |

Перед каждым cold-замером стек перезапускается, это 8 раз по ~20 с. Без перезапуска все замеры после первого шли бы на прогретом кэше.

Результат: `results.csv` и `results.json`. Графики строятся командой `python make_charts.py` (сохраняются в `docs/`).

Если мало времени: `python 02_benchmark.py --sf 1 --no-restart` идёт вдвое быстрее, но cold-замеры тогда недостоверны.

## Шаг 4. Silver и Gold (~2-3 мин)

```powershell
.\01_run_sql.ps1 sql\03_silver.sql
.\01_run_sql.ps1 sql\04_gold.sql
```

- Silver: отчёт о качестве данных, справочник клиентов, очищенный и обогащённый факт продаж (decimal вместо double, коды заменены на понятные значения, расчёт net, скидки и просрочки, join с заказами и товарами).
- Gold: три витрины. Выручка по регион x сегмент x месяц, сроки доставки по способу доставки, возвраты по брендам.

Контрольные SELECT в конце скриптов печатают цифры, которые есть в README.

Если после бенчмарка контейнер Trino не стартует (`exit 126`), запустить `finish.cmd`: он пересоздаст Trino и прогонит Silver и Gold.

## Выключить / почистить

```powershell
docker stop trino lakekeeper lakehouse-pg lakehouse-minio          # пауза
docker start lakehouse-minio lakehouse-pg lakekeeper trino         # обратно

docker rm -f trino lakekeeper lakehouse-pg lakehouse-minio         # удалить контейнеры
docker volume rm minio-data pg-data                                # удалить данные (~8 ГБ)
```

## Частые проблемы

| Что видно | Что делать |
|---|---|
| `port is already allocated` | `Get-NetTCPConnection -State Listen -LocalPort 8080`, закрыть процесс или поменять порт в `00_setup.ps1` |
| `Catalog 'tpch' not found` | Trino не перезапущен после правки `catalog\`, сделать `docker restart trino` |
| Trino падает на старте | `docker logs trino`, обычно опечатка в `.properties` |
| `pool timed out` у Lakekeeper | Postgres не успел подняться, `docker restart lakekeeper` |
| `pull access denied` на MinIO | нужен форк `pgsty/silo`, он уже прописан в скрипте |
| `Query exceeded memory` | уменьшить sf или дать Docker Desktop больше RAM (Settings -> Resources) |
| Docker не видит `catalog\` | в пути кириллица или пробелы, перенести папку |
